## Title

**Submit:** *Temporary Loss of Eligibility Cancels Exactly in Cross-Sectional HIV Incidence Estimation*

Eleven words. Three changes from the draft title:

- **"Temporary" for "Transient."** The whole point is a contrast with *absorbing* loss, and
  "temporary" carries that to a clinical reader without a definition. "Transient" also has a
  competing technical sense in Markov theory (a transient *state*), which is not what is meant.
- **"Cancels" for "Can cancel."** "Can" invites the reader to file this as a theoretical
  possibility. The result is an equality under stated conditions, and the conditions are named
  in the first line of Results. Assertive titles also survive CROI's programme listing better.
- Dropped "Bias" phrasing entirely so the title states the finding, not the topic.

Two alternates, if a co-author objects to an assertive title:

| | Title | Note |
|---|---|---|
| B | Eligibility Dynamics in Cross-Sectional HIV Incidence Estimation: Exact Cancellation and Its Failure Modes | Neutral, more conventional; buries the finding after a colon |
| C | When Does Leaving the Observable Population Bias HIV Incidence Estimates? | Question form; good for a poster walk-up, weaker in a citation |

Avoid the original's "Can Cancel Exactly" — reviewers read hedged titles as preliminary work.

## Resolved: the value of c

The brief flagged that exp(−θc) = 0.810 does not reproduce from θ = 0.844/y with c = 90 days,
which gives 0.8122, and asked whether c is 90 or 91 days.

**It is neither. `C_PURPOSE = 0.25` years exactly — 91.3125 days.** exp(−0.84397 × 0.25) =
0.80978, which is the 0.810 in the caption, and the Monte Carlo crossing interpolated from
`croi_figB_screening.csv` is 0.81044. The constant, the analytic boundary and the plotted
boundary already agreed; the error was the *label* "c = 90 days" in the old two-panel caption,
which is now gone from the submitted material along with panel B.

**One decision remains for the poster and the manuscript, and it is a modelling choice, not a
bug.** PURPOSE excludes on a 90-day testing window; the code uses a quarter-year. If fidelity to
the protocol is wanted, set `C_PURPOSE = 90 / 365.25` in `analysis/_common.py`, which moves the
no-dynamics boundary from 0.8098 to 0.8122 (+0.3%) and changes Table S4, the η surface and the
mortality threshold. It does not touch the submitted figure, which never uses c. Left unchanged
here rather than altered silently, because it is the sort of constant that should move by
decision.

Two wording notes on the numbers:

## Claims deliberately NOT made

Listed so nothing gets added back under deadline pressure.

- No claim that any specific published trial estimate is biased, or by how much. The abstract
  says when correction is and is not warranted.
- No claim about eta's value in any real population. It is a free parameter shown in both
  directions.
- No claim that the cancellation requires reversible or detailed-balanced movement. It needs
  stationarity only, and saying otherwise understates the result.
- No claim of exactness for the boundary beyond the Poisson inter-test case, where it holds
  exactly. Under a uniform inter-test process invariance is approximate (<=0.6%).
